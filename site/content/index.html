Completion checks for Claude Code and Codex, with evidence you can inspect.

actually-done compares an agent’s completion claims with current Git changes, fresh tests, and unfinished transcript work. Get a terminal, JSON, or Markdown receipt before you review or merge.

A repeatable check after an agent run

  1. Select a completed session
  2. Check Git and run tests
  3. Inspect findings and limits
  4. Decide your next step

Use it in the project the agent worked on

actually-done . --test "cargo test --locked"

Choose your project’s test command. Tests run locally and may change files or access the network. Explicitly waiving tests is supported and visible in the receipt.

Evidence, with limits attached

DONE means “no gaps detected by the available checks.” It does not prove correctness, security, deployment, or who changed a file. A claimed file may already be committed; existing changes may predate the session. Scope and unfinished-work findings are heuristics.

The CLI never uploads transcripts. No account or API key is required. If an agent reads the receipt, its configured model provider may receive that content.
