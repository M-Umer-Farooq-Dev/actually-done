Reproducible synthetic example

Tests pass. An obligation remains.

A passing test run does not close unfinished work in an agent handoff.

The claim

Done. Updated auth.py. We should rotate the key later.

This is a synthetic Claude transcript. There is no real credential or production key. The fixture project has an untracked auth.py and a small test that asserts its demonstration behavior.

Run the example

From the source checkout, with Python 3.11+ and the CLI installed:

python scripts/demo.py --binary actually-done

The script initializes an isolated temporary Git repository, writes synthetic transcript/code/test fixtures, runs the CLI with a fresh test command, and verifies the returned fields. It does not read your real sessions or change your project. Temporary files are removed after the run.

Why it helps

The developer sees the unfinished obligation without rereading every event. The receipt gives them a concrete follow-up to inspect before deciding whether the work can move on.

What this example does not establish

The demonstration test is deliberately small. It establishes that fresh tests can pass while an obligation remains; it is not a security test or evidence of production readiness. Language heuristics may miss other wording. The current Git snapshot does not establish who changed a file or when.
