Install actually-done

The CLI runs locally. The optional skill teaches your agent how to use it.

Install the CLI from source

You need Git and Rust 1.85 or newer. Dependencies download during the build.

git clone https://github.com/M-Umer-Farooq-Dev/actually-done.git
cd actually-done
cargo install --locked --path .
actually-done --version

There is currently no crates.io publication. Do not use cargo install actually-done until a registry release is announced.

Native downloads

The published releases are the source of available downloads. v0.1.0 has Windows x64. Cross-platform archives for Linux x64, macOS Apple Silicon, and Windows x64 are being prepared; CI artifacts are not a published release. Match the archive to your operating system and CPU, verify its SHA-256 checksum, preserve its license notices, and place the executable on PATH.

Run your first receipt

Move into the Git repository the agent worked on. Choose an authorized test command appropriate for that project.

actually-done . --test "cargo test --locked"
actually-done . --test "pytest -q" --json

These are alternatives, not commands to run blindly. Commands are argument lists; shell pipes, redirects, and compound commands are not supported inside --test.

Waive tests explicitly

actually-done . --no-test

The receipt records the waiver. Without configured tests or a waiver, tests are unverified. A test command can modify files or use the network.

Save a receipt

actually-done . --test "cargo test --locked" --json
actually-done . --test "cargo test --locked" --out receipt.md

The Markdown output’s parent must exist. Never target a transcript. Exit 1 carries an attention-needed receipt; exit 2 reports input/discovery errors on stderr. Read the verdict rules.
